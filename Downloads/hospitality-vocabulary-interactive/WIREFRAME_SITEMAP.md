### 📚 PHẦN 1: HỌC TẬP

#### 1.1 🎯 Lộ trình học tập (Learning Path)
- **9 Module Nghề Khách sạn** (Cơ bản → Quản lý)
  1. Nghiệp vụ Lễ tân (11 lessons, 30 phút)
  2. Nghiệp vụ Buồng phòng (11 lessons, 25 phút)
  3. Nghiệp vụ Ẩm thực (11 lessons, 35 phút)
  4. Xu hướng 2025 (9 lessons, 25 phút)
  5. Kỹ năng Đặt bàn (11 lessons, 20 phút)
  6. Dị ứng & Chế độ ăn (11 lessons, 25 phút)
  7. Dịch vụ Khách hàng (11 lessons, 30 phút)
  8. Nghiệp vụ Nhà hàng (12 lessons, 31 phút)
  9. An toàn Thực phẩm (11 lessons, 22 phút)
  10. Quản lý Khách sạn (11 lessons, 28 phút)

- **Trạng thái Module**: Chưa học / Đang học / Hoàn thành / Khóa
- **Thống kê**: Tiến độ %, Hoàn thành, Đang học, Chuỗi ngày, Tổng thời gian

#### 1.2 ⚡ Microlearning
- **Xu hướng 2025**:
  - Tech-driven Service (Mobile Check-in, AI Concierge, Smart Services)
  - Wellness & Bleisure (Sleep Kit, Workation, Quiet Zones)
  - Sustainability (Zero Waste, Local Sourcing, Green Certifications)

- **Module Học tập Toàn diện**: 10 module (giống Learning Path)

#### 1.3 📋 Danh sách Từ vựng
- **75 Thuật ngữ F&B Chuyên nghiệp**
- **Bộ lọc**:
  - Chuyên mục (11 categories)
  - Cấp độ (Cơ bản, Trung cấp, Nâng cao)
  - Tìm kiếm (EN/VI)
  - Sắp xếp (A-Z EN/VI, Chuyên mục, Cấp độ)
- **Phân trang**: Hiển thị từng trang
- **Thống kê**: Tổng số, Đang hiển thị, Đã học

#### 1.4 🟢 Từ vựng Cơ bản (Basic)
- **Flashcard System**:
  - Mặt trước: Thuật ngữ tiếng Anh, Chuyên mục, Câu ví dụ
  - Mặt sau: Tiếng Việt, IPA, Định nghĩa, Phát âm
  - Controls: Trước/Sau, Lật thẻ
  - Actions: Đánh dấu, Đã học, Ôn tập

#### 1.5 🟡 Từ vựng Trung cấp (Intermediate)
- Cấu trúc giống Cơ bản
- Nội dung phức tạp hơn

#### 1.6 🔴 Từ vựng Nâng cao (Advanced)
- Cấu trúc giống Cơ bản
- Thuật ngữ chuyên sâu

### 🎯 PHẦN 2: THỰC HÀNH

#### 2.1 📝 Kiểm tra (Quiz)
- **Header**: Số câu hỏi hiện tại/tổng, Điểm số
- **Câu hỏi**: Text + Audio pronunciation
- **4 lựa chọn** (Multiple choice)
- **Controls**: Trả lời, Bỏ qua
- **Feedback**: Đúng/Sai + Giải thích
- **Kết quả cuối**: Điểm số, Độ chính xác, Làm lại, Xem lỗi sai

#### 2.2 🎭 Tình huống (Scenarios)
- **11 Chuyên mục Chuyên môn**:
  1. Dị ứng & Chế độ ăn
  2. Chuyên môn đồ uống
  3. Dịch vụ khách hàng
  4. Kỹ thuật chế biến
  5. Marketing & Sales
  6. Phân loại thực đơn
  7. Phong cách phục vụ
  8. Quản lý khách sạn
  9. Kỹ năng đặt bàn
  10. Vận hành bếp

- **Bộ lọc**: Chuyên mục, Cấp độ
- **Thống kê**: Tổng số, Đang hiển thị, Đã hoàn thành

- **Cấu trúc Tình huống**:
  - Mô tả tình huống (Situation)
  - 3-4 lựa chọn xử lý (A, B, C, D)
  - Feedback: Giải thích + Thuật ngữ chuyên môn
  - Navigation: Trước/Sau, Quay lại danh mục

## 🎨 DESIGN SYSTEM

### Colors
- **Primary**: Blue/Sky tones (for actions, links)
- **Success**: Green (completed, correct)
- **Warning**: Yellow/Orange (intermediate level)
- **Error**: Red (advanced level, errors)
- **Neutral**: Gray scale

### Typography
- **Font Family**: FKGroteskNeue, system fonts
- **Headings**: Bold, larger sizes
- **Body**: Regular weight
- **Code/Terms**: Monospace for IPA pronunciation

### Components
- **Cards**: Rounded corners, shadow, hover effects
- **Buttons**: Primary (filled), Secondary (outlined), Small
- **Badges**: Level indicators (🟢🟡🔴), Status badges
- **Progress bars**: Linear, circular (ring)
- **Modals**: Lesson preview, notifications
- **Icons**: Unicode emoji + Lucide Icons

### Responsive Design
- **Mobile-first**: Works on all screen sizes
- **Sidebar**: Collapsible on mobile
- **Grid**: Auto-responsive (Flexbox/Grid)

### Flow 1: Học từ vựng mới
```
Dashboard → Vocabulary (Basic/Intermediate/Advanced) → 
Flashcard → Flip → Learn → Next → Mark as Learned → Progress Update
```

```
Dashboard → Quiz → Answer Questions (10) → 
Submit → Feedback → Next Question → Results → Review Mistakes / Retake
```

### Flow 3: Thực hành tình huống
```
Dashboard → Scenarios → Filter Category/Level → 
Select Scenario → Read Situation → Choose Option → 
Feedback + Key Phrases → Next Scenario → Complete
```

```
Dashboard → Learning Path → Select Module → 
View Module Details → Start Lesson → 
Complete Lesson → Mark Complete → Next Lesson → 
Complete Module → Progress Update
```

### Flow 5: Microlearning
```
Dashboard → Microlearning → Select Trend Topic / Module → 
Start Quick Lesson → Complete (2-7 min) → 
Earn Points → Next Lesson
```
